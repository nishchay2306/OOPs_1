#   OOPs_1 - Object-Oriented Programming Practice

Welcome to my first OOP journey! This repository contains the problem statements and solutions I worked through while learning the fundamentals of Object-Oriented Programming.

📚 Topics Covered
- Classes & Objects: Understanding blueprints and instances
- Encapsulation: Data hiding and access modifiers
- Inheritance: Reusing code through class hierarchies
- Polymorphism: One interface, multiple implementations
- Abstraction: Simplifying complex systems

🛠️ How to Use
1. Clone this repository:  
   bash
   git clone https://github.com/nishchay2306/OOPs_1.git

2. Navigate to any problem directory:  
   bash
   cd OOPs_1/src/problem1

3. Compile and run (adjust for your language):
    - Java: javac Main.java && java Main
    - C++: g++ main.cpp -o main && ./main
    - Python: python main.py
